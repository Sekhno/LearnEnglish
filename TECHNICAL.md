# Техническое задание: веб-приложение для изучения английского языка

Цель проекта: разработать интерактивную образовательную платформу для самостоятельного изучения английского языка с нуля до продвинутого уровня (A1–C1).

Главная идея — не просто показывать пользователю правила грамматики и упражнения, а создать систему последовательного обучения, в которой теория закрепляется практикой, новые слова используются в реальных ситуациях, а приложение адаптируется к знаниям пользователя.

## 1. Концепция обучения

Каждая тема должна состоять из нескольких взаимосвязанных этапов.

Теория

Примеры

Практика

Диалог

Проверка

Обязательная структура каждой учебной темы:

1. Теоретический раздел (Theory) — объяснение правил простым языком, таблицы, структуры предложений, положительные и отрицательные формы, распространённые ошибки.
2. Примеры (Examples) — предложения с переводом, аудиопроизношением и разбором отдельных слов.
3. Практический раздел (Practice) — интерактивные упражнения разных типов, от простых до сложных.
4. Применение (Real-Life Usage) — диалоги, жизненные ситуации, задания на самостоятельное построение предложений.
5. Проверка знаний (Assessment) — итоговый мини-тест и персонализированная работа над ошибками.

## 2. Полная программа изучения английского

Программу следует разделить по уровням CEFR. Темы ниже — базовый учебный план; при разработке контента каждая строка должна превратиться в самостоятельный урок с теоретическим и практическим разделами.

## 5. Пример полноценного интерактивного урока

Рассмотрим пример того, как должен выглядеть урок Present Simple.

A1 · GRAMMAR · LESSON 11

# Present Simple

Регулярные действия и повседневные привычки

Demo

### Теория

Present Simple используется для привычек, регулярных действий и общих фактов.

Утверждение

I / You / We / They + verb

He / She / It + verb + s/es

I work every day. — Я работаю каждый день.

She works every day. — Она работает каждый день.

Для вопросов используются do/does, для отрицаний — don't/doesn't. После does и doesn't основной глагол имеет начальную форму.

### Практика: выбери правильный ответ

Задание 1 из 3

Верно: 0

She \_\_\_ English every morning.

study

studies

studying

Правильный ответ: studies

С he/she/it к study добавляется -ies.

Следующее задание

Это упрощённая демонстрация. В реальном приложении после каждого ответа необходимо показывать объяснение, а ошибки включать в будущие повторения.

Личный кабинет должен отображать текущий уровень, изученные темы, ежедневную цель, новые слова, задания для повторения и рекомендации следующего урока. Отдельно необходимо отслеживать навыки Reading, Writing, Listening и Speaking.

### 6.2. Адаптивное обучение

- Входной тест для определения стартового уровня.
- Автоматическое изменение сложности упражнений в зависимости от результатов.
- Повторение ошибок через определённые интервалы.
- Возможность пропустить известную тему после проверки знаний.
- Рекомендации тем по выявленным слабым местам.

### 6.3. Система повторения

Использовать алгоритм интервального повторения (Spaced Repetition), например FSRS.

Для слов, грамматических конструкций и типичных ошибок хранить историю ответов и вычислять дату следующего повторения.

### 6.4. Работа с произношением

Пользователь должен иметь возможность прослушать эталонное аудио, записать свою речь, получить транскрипцию и сравнить её с ожидаемой фразой. Оценивание произношения требует отдельного механизма фонетического анализа: обычное распознавание речи само по себе не даёт надёжной оценки качества произношения.

### 6.5. AI Assistant

AI-преподаватель должен уметь:

- Объяснять грамматические правила простыми словами.
- Генерировать дополнительные упражнения по конкретной теме.
- Исправлять предложения с пояснением причин.
- Поддерживать разговорные диалоги на уровне пользователя.
- Помогать составлять короткие рассказы, сообщения и деловые письма.

### 7.1. Модель данных

Важно хранить контент отдельно от компонентов интерфейса. Тогда можно создавать сотни новых уроков без изменения frontend-кода.

Предлагаемая структура:

| Entity            | Назначение                          |
| ----------------- | ----------------------------------- |
| `Level`           | CEFR A1–C1                          |
| `Course`          | Учебный курс                        |
| `Module`          | Тематический раздел                 |
| `Topic`           | Тема с зависимостями и метаданными  |
| `Lesson`          | Отдельный урок                      |
| `TheoryBlock`     | Теоретический материал              |
| `Example`         | Пример с переводом и аудио          |
| `Exercise`        | Тип, условия и настройки упражнения |
| `ExerciseItem`    | Вопросы и варианты ответов          |
| `VocabularyEntry` | Слово, IPA, перевод, примеры        |
| `UserProgress`    | Прогресс по урокам                  |
| `Attempt`         | История попыток и ответов           |
| `ReviewItem`      | Данные интервального повторения     |

Для `Exercise` желательно использовать расширяемый JSON-контент с обязательной схемной валидацией. Например:

```
{
  "id": "present-simple-001",
  "topicId": "present-simple",
  "level": "A1",
  "type": "multiple_choice",
  "difficulty": 1,
  "question": "She ___ coffee every morning.",
  "options": ["drink", "drinks", "drinking"],
  "correctAnswer": "drinks",
  "explanation": {
    "ru": "После he, she, it глагол получает окончание -s."
  },
  "tags": ["third-person-singular"],
  "estimatedSeconds": 30
}
```

В production правильные ответы необходимо проверять на backend. Клиенту не следует заранее передавать эталон, если упражнение является частью контрольного тестирования.

## 8. Требования к качеству образовательного контента

Каждый опубликованный урок должен удовлетворять минимальным критериям:

| Элемент    | Минимальное требование                              |
| ---------- | --------------------------------------------------- |
| Теория     | Объяснение, грамматическая формула, типичные ошибки |
| Примеры    | 5–10 контекстных примеров                           |
| Упражнения | Не менее 10 заданий разных типов                    |
| Аудио      | Озвучивание примеров и слов                         |
| Словарь    | Связанные слова и выражения                         |
| Практика   | Хотя бы одна жизненная ситуация                     |
| Проверка   | Итоговый тест с объяснениями                        |
| Повторение | Ошибочные элементы попадают в очередь повторения    |

Количество заданий должно зависеть от сложности темы: для некоторых вопросов достаточно 10–15, для больших грамматических тем может потребоваться несколько отдельных уроков.

## 9. Этапы реализации (MVP → Full Product)

1. MVP — базовое обучение

   Уровень A1, теория, упражнения Multiple Choice / Fill in the Blanks / Sentence Builder, пользовательский прогресс, тесты и базовый словарь.
2. Vocabulary & Listening

   Тематические словари, карточки, TTS-аудио, аудирование и интервальное повторение.
3. Speaking & AI

   AI-диалоги, голосовые упражнения, персонализированные объяснения ошибок.
4. Adaptive Learning

   Входное тестирование, рекомендации, динамическая сложность, аналитика прогресса.
5. Full Curriculum & Content Management

   Уровни A2–C1, редактор уроков, управление версиями контента, локализация и расширенная аналитика.

## 10. Критерии готовности MVP

MVP можно считать готовым, когда пользователь способен зарегистрироваться, определить или выбрать начальный уровень, открыть любую опубликованную тему A1, изучить теорию, пройти интерактивные упражнения, увидеть объяснения ошибок, завершить контрольный тест и после повторного входа продолжить с сохранённого прогресса.

Система должна поддерживать корректное отображение на мобильных устройствах, доступное управление с клавиатуры, сохранение незавершённых занятий, а также независимое добавление учебного контента без изменения кода приложения.

## 11. Главная рекомендация по архитектуре обучения

Я бы разделил приложение на три самостоятельные, но связанные образовательные системы:

- Grammar Learning — последовательное изучение правил, структура языка и упражнения.
- Vocabulary Learning — слова, устойчивые выражения, аудио и интервальные повторения.
- Language Practice — разговорные ситуации, аудирование, чтение, письмо и AI-тренировки.

Например, пользователь изучает Present Simple в Grammar, получает слова из темы Daily Routine в Vocabulary, а затем применяет всё это в разговоре Tell me about your typical day в Language Practice.

Именно такая связь позволит сделать приложение не просто электронным учебником с тестами, а полноценной системой самостоятельного изучения английского языка.
